HƯỚNG DẪN CÀI ĐẶT IPHONE (iOS)

Khắc phục 100% lỗi "Không thể xác minh tính toàn vẹn của ứng dụng"

CÁCH 1 Dùng 3uTools trên Máy Tính (Khuyên Dùng - Chuẩn 100%)
  1. Tải file FCMA.ipa về máy tính.
  2. Tải và mở phần mềm 3uTools (tại 3u.com).
  3. Cắm cáp sạc kết nối iPhone với máy tính -> Bấm "Tin cậy" trên màn hình iPhone.
  4. Trên 3uTools, chọn mục Toolbox -> chọn IPA Signature -> Thêm file FCMA.ipa.
  5. Chọn Sign with Apple ID (nhập tài khoản Apple ID cá nhân của bạn) -> Bấm Start Signing.
  6. Ký xong, bấm cài đặt vào iPhone là vào game chơi vĩnh viễn không bao giờ bị thu hồi hay lỗi xác minh!
CÁCH 2 Cài Trực Tiếp Bằng Scarlet / ESign (Không Cần Máy Tính)
  1. Dùng Safari trên iPhone mở trang usescarlet.com và bấm Direct Install để cài Scarlet.
  2. Tải file FCMA.ipa về iPhone (lưu vào Tệp / Files).
  3. Mở ứng dụng Scarlet -> Bấm nút nhập file ở góc trên -> Chọn file FCMA.ipa vừa tải để Scarlet tự động cài đặt.
  4. Nếu iPhone báo "Nhà phát triển chưa tin cậy": Vào Cài đặt máy -> Cài đặt chung -> Quản lý VPN & Thiết bị -> Bấm Tin cậy là xong!
Dành cho iOS 16, 17, 18 trở lên: Nếu mở game bị văng, vào Cài đặt -> Quyền riêng tư & Bảo mật -> Chế độ nhà phát triển (Developer Mode) -> Bật On và khởi động lại iPhone.
