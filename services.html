Chatbot cho Facebook Messenger, Zalo OA, WhatsApp, Website — hiểu ngữ cảnh, trả lời tự nhiên bằng tiếng Việt, kết nối trực tiếp CRM/kho hàng.

  • ✓ Huấn luyện từ tài liệu sản phẩm, FAQ, chính sách bảo hành

02 · AI Agent

AI Agent tự chủ — gọi tool, ra quyết định, chạm hệ thống

Agent hiểu mục tiêu, tự lập kế hoạch nhiều bước, gọi API nội bộ và bên thứ ba, xử lý ngoại lệ. Có sẵn framework LangGraph / OpenAI Function Calling.

  • ✓ Multi-tool: CRM, ERP, Sheets, email, SMS, Notion
  • ✓ Human-in-the-loop cho quyết định quan trọng
  • ✓ Log & trace đầy đủ để audit
